**Android:** download `Fishamongus-<version>.apk` on your phone and open it. Android asks once to allow installs from your browser or file manager (Settings → Apps → Special app access → Install unknown apps). Installing a newer APK later updates the app and keeps your log.

**Windows 10/11:** run `FishamongusSetup-<version>.exe`. It installs for you only (no administrator needed). SmartScreen may warn because the file isn't code-signed: More info → Run anyway.

Both work offline, maps included, once installed; weather, tides, alerts and new map tiles need a connection. Each install keeps its own log on that device; move catches between them with Settings → Backup and Import a log.
